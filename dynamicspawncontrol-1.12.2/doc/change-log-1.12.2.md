# Список изменений

## Релиз 0.1 (ДАТА)

### Искусственный ителлект

- Добавлена новая ИИ задача для сущности типа "Паук": Сущность такого типа избегает ярких источников света, если сущность находится под землей, ниже 50 блоков
- Добавлена новая ИИ задача для сущности типа "Зомби": Сущность целенаправленно ищут под землей факел, чтобы его уничтожить

### Генерация блоков

- Добавлена усиленная генерация изумрудов в подземельях (Только основной мир)
- Добавлена случайная генерация каменных блоков с монстрами в подземельях (Только основной мир)
- Добавлена генерация замшелых булыжников в подземельях (Только основной мир)
- Добавлена генерация адского камня в подземельях на глубине ниже 15 блоков (Только основной мир)
- Добавлена генерация арбузов возле водянных биомов в обычном мире (Только основной мир)

### Консольные команды

- Добавлена консольная команда /dsc_dump_block. Предоставляет информацию о блоке, на который наведен курсор
- Добавлена консольная команда /dsc_dump_entity. Предоставляет информацию о живой сущности, на которую наведен курсор
- Добавлена консольная команда /dsc_dump_item. Предоставляет информацию о предмете, который находится у игрока в руках
- Добавлена консольная команда /dsc_gm. Позволяет быстро переключить игровой режим
- Добавлена консольная команда /dsc_gd. Предоставляет информацию (ID) о игровом мире
- Добавлена консольная команда /dsc_moon_phase. Предоставляет информацию о текущей фазе луны
- Добавлена консольная команда /dsc_lf. Запускает огненный шар, который взрывается при столкновении с твердой поверзностью
- Добавлена консольная команда /dsc_scan_entities. Сканирует живых сущностей в радиусе игрока, информация записывается в лог-журнал
- Добавлена консольная команда /dsc_sv. Консольная команда администратора, выдает эффект ускорения и невидимости
- Добавлена консольная команда /dsc_clean_up_memory. Отвечает за клиентскую очистку памяти в игре
- Добавлена консольная команда /dsc_mob_killer. Удаляет выбранный тип сущности
- Добавлена консольная команда /dsc_reload_scripts. Консольная команда администратора, перезагружает скрипты парсеров с параметрами
